# What matters when this app is tested

## Critical user flows (P0)
1. Creating a device: an administrator adds a device from DCIM > Devices > Add, sets its site, role, device type and rack position, and it saves.
2. Assigning an IP address: an administrator assigns an IP address to a device interface from IPAM > IP Addresses.

## Accounts and roles
- An administrator account manages devices and IP addresses; a regular user cannot.

## Matters least
- The About page: cosmetic only.
- Creating a device: matters least; do not test it.
